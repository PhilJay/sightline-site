Claude Code reads your files and runs your commands, but it has to guess how the UI looks until it gets a picture. Pasting a screenshot works once. When the agent should check its own work, mark what is wrong and try again, it is faster when it can take the screenshot itself.

Sightline is a Mac screenshot and screen recording app with an MCP server and a command line tool built in. Connect Claude Code, Claude Desktop, Codex or another MCP client and ask in plain words. The agent works in the same app and editor you use.
  • Capture a window, an area or a display, and get the file and a preview back
  • Compare with a design and get up to 20 numbered differences, each shifted, only in the design, only on screen or looking different
  • Mark it up with boxes, arrows, text, step numbers and blur
  • Edit live in the Sightline editor you have open, as one undo step you can change or undo
  • Read the screen: text, QR codes and colors
  • Record up to 60 seconds, then cut, speed up, zoom on clicks or export a GIF
  • Search old captures by the text inside them
  • Blur secrets that look like passwords, keys or tokens before it shares
    •

    Ask “Compare the sign up screen in the Simulator with signup-design.png and fix what differs.” Claude Code runs the same check as Show Differences on a pinned design: it lines the design up, numbers every spot that differs and says whether it moved, is missing or only looks different. It changes the code, the app reloads, and it checks again until the list is empty.

    You can run the check yourself too. Pin the design over your running app, turn on Show Differences, and with Tracing your clicks go through to the app while the marks follow your changes.
  • Install SightlineGet it from the Mac App Store and allow Screen Recording.
  • Turn on AI AgentsIn Settings › AI Agents, turn on Allow AI agents to use Sightline and click Connect next to Claude Code.
  • Start a new sessionRun claude mcp list or /mcp to see sightline, then ask for a screenshot.
    •

    Prefer the terminal? claude mcp add --scope user sightline -- "/Applications/Sightline.app/Contents/MacOS/sightline-cli" mcp does the same. All tools are in the MCP reference and the command line docs.

    Claude Code also has a built-in computer use server on macOS, a research preview at the time of writing. It lets Claude open apps, click, type and take screenshots. Use it when the agent has to operate an app, for example to click through onboarding.

    Use Sightline when the agent needs a capture tool: a sharp screenshot of one window, a design check with numbered differences, marks you can still edit, a searchable history and a recording you can cut. The two work well together, and Anthropic’s docs say Claude reaches for a dedicated MCP server first when one fits the task.
