Claude Code can’t see your UI until you give it a picture. With Sightline, a Mac screenshot app with a built-in MCP server, Claude Code takes the screenshot itself, checks its work and tries again.

Claude Code calls sightline-cli, a small MCP server inside the app. Sightline captures on your Mac and sends back the image with numbered differences.
  • Capture a window, an area or a display
  • Compare to a design with numbered differences
  • Mark up with boxes, arrows, text and blur
  • Edit live in the Sightline editor you have open
  • Read the screen: text, QR codes and colors
  • Record up to 60 seconds, then cut or export a GIF
    •

    Ask “Compare the sign up screen in the Simulator with signup-design.png and fix what differs.” Claude Code numbers each mismatch, fixes the code and checks again until none are left.
  • Install SightlineFrom the Mac App Store, then allow Screen Recording.
  • Click ConnectIn Settings › AI Agents, turn on agent access and click Connect next to Claude Code.
  • Ask for a screenshotStart a new session. /mcp lists sightline.
    •  claude mcp add --scope user sightline -- \ "/Applications/Sightline.app/Contents/MacOS/sightline-cli" mcp

    Prefer the terminal? The command above does the same. Every tool is in the MCP reference, and Codex or Cursor users can set up the same screenshot MCP server in their client.
