Agents can’t see your screen on their own. Sightline is a Mac screenshot app with a screenshot MCP server built in, so Claude Code, Claude Desktop, Codex, Cursor or any MCP client can take the screenshot itself.

The Mac App Store version has 24 tools. The same tools run from the terminal with sightline-cli.

  • Capture a display, an area or a window by app or title
  • Read the screen: text, QR codes, barcodes and colors
  • Compare with a design and get numbered differences
  • Mark up with boxes, arrows, numbers, text and blur
  • Record up to 60 seconds, then cut, zoom or export a GIF
  • Find old captures by the text inside them
    •
  • Turn on agent accessIn Sightline, open Settings › AI Agents and turn on Allow AI agents to use Sightline.
  • Click ConnectOne click for Claude Code, Claude Desktop and Codex CLI. Then start a new session.
  • Or add it by handAny client that starts a stdio server works, such as Cursor.
    •

    Cursor reads this entry from ~/.cursor/mcp.json, Claude Desktop from its claude_desktop_config.json:

    { "mcpServers": { "sightline": { "command": "/Applications/Sightline.app/Contents/MacOS/sightline-cli", "args": ["mcp"] } } }

    Codex CLI reads a block in ~/.codex/config.toml. Both are in the MCP setup guide.

    A small script around macOS screencapture returns a raw image. Sightline does the capture in its own app and adds what an agent needs next.

  • Editable results that open in the Sightline editor
  • Live edits in the editor you already have open
  • Design checks that number every mismatch
  • Smaller context when a file path is enough
    •
  • Off until you turn it on in Settings › AI Agents
  • Each agent asks first: once, this session or always
  • A banner names the agent on every capture
  • Local only: no account, no analytics, no network
