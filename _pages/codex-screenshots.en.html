Codex CLI sees a screenshot when you paste it or pass it with codex -i. With Sightline, a Mac screenshot app with a built-in MCP server, Codex takes the screenshot itself, checks its fix and tries again.

Codex starts sightline-cli mcp, a small server inside the app. Sightline captures with its own permissions and sends back the file path and a preview image.

  • Capture a window by app or title, an area or a display
  • Compare with a design and get numbered differences
  • Read the screen: text, QR codes and colors
  • Mark up with boxes, arrows, numbers, text and blur
  • Record up to 60 seconds, then cut or export a GIF
  • Work in your editor on the screenshot you have open

  • Turn on agent accessIn Sightline, open Settings › AI Agents and turn on Allow AI agents to use Sightline.
  • Click ConnectNext to Codex CLI. The first time, choose the folder that holds the Codex config.
  • Start a new Codex sessionThen ask Codex to take a screenshot.

    Prefer to do it yourself? Add this block to ~/.codex/config.toml:

    [mcp_servers.sightline] command = "/Applications/Sightline.app/Contents/MacOS/sightline-cli" args = ["mcp"]

    Or click Let your agent connect itself and paste the prompt into Codex. All three ways are in the Codex CLI setup guide.
  • Check the design: “Compare the running app with signup-design.png and fix what differs.”
  • Mark a bug: “Screenshot the Simulator and box the misaligned button.”
  • Read an error: “Read the text in the Terminal window and explain the failing test.”
  • Reuse a capture: “Find the screenshot with the error code E1042 from this week.”
