Von sich aus sehen Agenten deinen Bildschirm nicht. Sightline ist eine Screenshot-App für den Mac mit eingebautem Screenshot-MCP-Server: Claude Code, Claude Desktop, Codex, Cursor oder jeder andere MCP-Client macht den Screenshot einfach selbst.

Die Version aus dem Mac App Store hat 24 Werkzeuge. Im Terminal laufen dieselben über sightline-cli.

  • Aufnehmen: Bildschirm, Bereich oder Fenster nach App oder Titel
  • Den Bildschirm lesen: Text, QR-Codes, Barcodes und Farben
  • Mit dem Design vergleichen, Unterschiede nummeriert
  • Beschriften mit Rahmen, Pfeilen, Nummern, Text und Unschärfe
  • Aufzeichnen bis zu 60 Sekunden, dann schneiden, zoomen oder als GIF exportieren
  • Alte Aufnahmen finden über den Text darin
    •
  • Agentenzugriff einschaltenIn Sightline unter Einstellungen › KI-Agenten „KI-Agenten dürfen Sightline verwenden“ einschalten.
  • Verbinden klickenEin Klick für Claude Code, Claude Desktop und Codex CLI. Danach eine neue Sitzung starten.
  • Oder selbst eintragenJeder Client, der einen stdio-Server startet, funktioniert, etwa Cursor.
    •

    Cursor liest diesen Eintrag aus ~/.cursor/mcp.json, Claude Desktop aus seiner claude_desktop_config.json:

    { "mcpServers": { "sightline": { "command": "/Applications/Sightline.app/Contents/MacOS/sightline-cli", "args": ["mcp"] } } }

    Codex CLI liest einen Block in ~/.codex/config.toml. Beides steht in der MCP-Anleitung (Englisch).

    Ein kleines Skript rund um screencapture von macOS liefert ein rohes Bild. Sightline nimmt in der eigenen App auf und liefert gleich mit, was ein Agent als Nächstes braucht.

  • Bearbeitbare Ergebnisse, die sich im Sightline-Editor öffnen
  • Live bearbeiten im Editor, den du gerade offen hast
  • Design-Vergleiche, die jede Abweichung nummerieren
  • Weniger Kontext, wenn ein Dateipfad reicht
    •
  • Aus, bis du es einschaltest, in Einstellungen › KI-Agenten
  • Jeder Agent fragt zuerst: einmal, pro Sitzung oder immer
  • Ein Hinweis nennt den Agenten bei jeder Aufnahme
  • Nur lokal: kein Konto, keine Analyse, kein Netz
    •      Ein Programm, über das ein KI-Agent per Model Context Protocol Screenshots macht und liest. Bei Sightline ist das sightline-cli mcp, das in der App steckt. Nein, nur Sightline. Der Server gibt jeden Aufruf an die laufende Sightline-App weiter, und die nimmt mit ihren eigenen Rechten auf. Ja, bis zu 60 Sekunden pro Aufruf ab macOS 15. Mikrofon und Kamera sind bei Aufzeichnungen von Agenten nie dabei. Auf Macs mit Apple Intelligence ja. Mit „Aufnahmen auf vertrauliche Inhalte prüfen“ und „Erkannte Zugangsdaten vor Agenten verbergen“ wird Text, der wie ein Passwort, Schlüssel oder Token aussieht, in Bildern für Agenten unscharf. Sightline ist ein kostenloser Download. Der Zugriff für Agenten gehört zu Sightline Pro: 7 Tage gratis, dann 3,99 $ im Monat, 24,99 $ im Jahr oder einmalig 29,99 $ (US-Preise).
