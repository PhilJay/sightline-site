Claude Code sieht deine Oberfläche erst, wenn es ein Bild bekommt. Mit Sightline, einer Screenshot-App für den Mac mit eingebautem MCP-Server, macht Claude Code den Screenshot selbst, prüft seine Arbeit und versucht es nochmal.

Claude Code ruft sightline-cli auf, einen kleinen MCP-Server in der App. Sightline nimmt auf deinem Mac auf und schickt das Bild mit nummerierten Unterschieden zurück.
  • Aufnehmen: Fenster, Bereich oder Bildschirm
  • Mit dem Design vergleichen, Unterschiede nummeriert
  • Beschriften mit Rahmen, Pfeilen, Text und Unschärfe
  • Live bearbeiten im offenen Sightline-Editor
  • Den Bildschirm lesen: Text, QR-Codes und Farben
  • Aufzeichnen bis zu 60 Sekunden, dann schneiden oder als GIF exportieren
    •

    Frag: „Vergleiche den Registrierungs-Screen im Simulator mit signup-design.png und behebe, was abweicht.“ Claude Code nummeriert jede Abweichung, ändert den Code und prüft wieder, bis keine mehr übrig ist.
  • Sightline installierenAus dem Mac App Store laden und die Bildschirmaufnahme erlauben.
  • Verbinden klickenIn Einstellungen › KI-Agenten den Zugriff einschalten und bei Claude Code auf Verbinden klicken.
  • Um einen Screenshot bittenNeue Sitzung starten. /mcp zeigt sightline.
    •  claude mcp add --scope user sightline -- \ "/Applications/Sightline.app/Contents/MacOS/sightline-cli" mcp

    Lieber im Terminal? Der Befehl oben macht dasselbe. Alle Werkzeuge stehen in der MCP-Referenz (Englisch).
  • Aus, bis du es einschaltest, in Einstellungen › KI-Agenten
  • Jeder Agent fragt zuerst: Ablehnen, Einmal erlauben, Für diese Sitzung erlauben oder Immer erlauben
  • Du siehst jede Aufnahme: ein Hinweis nennt den Agenten, standardmäßig an
  • Kein Konto, keine Analyse, kein Sightline-Server
