Claude Code liest deine Dateien und führt deine Befehle aus, muss aber raten, wie die Oberfläche aussieht, bis es ein Bild bekommt. Einen Screenshot einzufügen klappt einmal. Soll der Agent seine Arbeit selbst prüfen, markieren, was nicht stimmt, und es nochmal versuchen, geht es schneller, wenn er den Screenshot selbst macht.

Sightline ist eine Screenshot- und Bildschirmaufnahme-App für den Mac mit eingebautem MCP-Server und Kommandozeilenwerkzeug. Verbinde Claude Code, Claude Desktop, Codex oder einen anderen MCP-Client und frag in normalen Worten. Der Agent arbeitet in derselben App und demselben Editor wie du.
  • Aufnehmen: ein Fenster, einen Bereich oder einen Bildschirm, mit Datei und Vorschau zurück
  • Mit dem Design vergleichen: bis zu 20 nummerierte Unterschiede, jeweils verschoben, nur im Design, nur am Bildschirm oder anders aussehend
  • Beschriften mit Rahmen, Pfeilen, Text, Schrittnummern und Unschärfe
  • Live bearbeiten im offenen Sightline-Editor, als ein Schritt, den du ändern oder widerrufen kannst
  • Den Bildschirm lesen: Text, QR-Codes und Farben
  • Aufnehmen bis zu 60 Sekunden, dann schneiden, beschleunigen, auf Klicks zoomen oder als GIF exportieren
  • Alte Aufnahmen finden über den Text darin
  • Geheimnisse unkenntlich machen, die wie Passwörter, Schlüssel oder Tokens aussehen, bevor geteilt wird
    •

    Frag: „Vergleiche den Registrierungs-Screen im Simulator mit signup-design.png und behebe, was abweicht.“ Claude Code macht dieselbe Prüfung wie Unterschiede zeigen bei einem angehefteten Design: Es richtet das Design aus, nummeriert jede abweichende Stelle und sagt, ob sie verschoben ist, fehlt oder nur anders aussieht. Dann ändert es den Code, die App lädt neu, und es prüft wieder, bis die Liste leer ist.

    Du kannst die Prüfung auch selbst machen. Hefte das Design über deine laufende App, schalte Unterschiede zeigen ein, und mit Nachzeichnen gehen deine Klicks an die App, während die Markierungen deinen Änderungen folgen.
  • Sightline installierenLade es aus dem Mac App Store und erlaube die Bildschirmaufnahme.
  • KI-Agenten einschaltenSchalte in Einstellungen › KI-Agenten den Zugriff für KI-Agenten ein und klick bei Claude Code auf Verbinden.
  • Neue Sitzung startenMit claude mcp list oder /mcp siehst du sightline. Dann bitte um einen Screenshot.
    •

    Lieber im Terminal? claude mcp add --scope user sightline -- "/Applications/Sightline.app/Contents/MacOS/sightline-cli" mcp macht dasselbe. Alle Werkzeuge stehen in der MCP-Referenz und der Doku zur Kommandozeile (beide Englisch).

    Claude Code hat unter macOS auch einen eingebauten Server für Computer Use, derzeit eine Forschungsvorschau. Damit kann Claude Apps öffnen, klicken, tippen und Screenshots machen. Nutze ihn, wenn der Agent eine App bedienen muss, etwa um sich durch ein Onboarding zu klicken.

    Nutze Sightline, wenn der Agent ein Aufnahmewerkzeug braucht: einen scharfen Screenshot eines Fensters, einen Design-Vergleich mit nummerierten Unterschieden, Markierungen, die du noch bearbeiten kannst, einen durchsuchbaren Verlauf und eine Aufnahme, die du schneiden kannst. Beides passt gut zusammen, und laut Anthropics Doku greift Claude zuerst zu einem passenden MCP-Server, wenn es einen gibt.
  • Aus, bis du es einschaltest, in Einstellungen › KI-Agenten
  • Jeder Agent fragt zuerst: Ablehnen, Einmal erlauben, Für diese Sitzung erlauben oder Immer erlauben
  • Du merkst jede Aufnahme: ein Hinweis nennt den Agenten, standardmäßig an
  • Ein Ordner: Agenten speichern im Agent-Ordner und lesen nur dort und was du öffnest
  • Kein Mikrofon, keine Kamera in Aufnahmen, die ein Agent macht
  • Auf deinem Mac: kein Konto, keine Analyse, kein Sightline-Server
